# Avatar Community App

A mobile community application built with React Native (Expo), where users can create avatars and interact through posts, comments, likes, and voting features.

---

## 🚀 Features

- Avatar system (profile customization)
- Post creation, editing, and deletion
- Comments and nested replies
- Like and view count system
- Poll creation and participation
- Image upload (custom assets excluded from repository)
- Multi-language support (i18n)
- Push notifications
- Infinite scroll
- Optimistic UI updates

---

## 🛠 Tech Stack

- React Native (Expo)
- Expo Router
- TypeScript
- React Query (TanStack Query)
- React Hook Form
- Day.js
- i18n (Internationalization)
- JWT Authentication
- Expo Push Notifications
- EAS (Build & Deployment)

---

## 🧩 Implementation Details

- Common reusable components
- Custom hooks pattern
- Server state management with React Query
- Form handling with React Hook Form
- Date handling with Day.js
- SVG usage and custom font integration
